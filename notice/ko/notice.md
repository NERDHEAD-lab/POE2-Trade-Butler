## Notice

### 3.0.1 업데이트 - 카카오게임즈 거래소 도메인 변경 대응

POE2 Trade Butler는 3.0.0 버전 배포 이후 안정화 상태로 운영되었으며, 최근까지 큰 기능 변경 없이 유지되고 있었습니다.

이번 3.0.1 업데이트는 한국 POE2 거래소 주소가 카카오게임즈 도메인으로 변경된 것에 대응하기 위한 유지보수 업데이트입니다.
```
기존 Daum 거래소 주소:
https://poe.game.daum.net/trade2/...

새 Kakao Games 거래소 주소:
https://poe.kakaogames.com/trade2/...
```

이번 업데이트에는 다음 내용이 포함됩니다.

```
카카오게임즈 거래소 도메인에서 확장 프로그램이 동작하도록 변경했습니다.
기존 Daum 거래소 주소로 저장되어 있던 검색 히스토리를 새 주소로 이전합니다.
기존 Daum 거래소 주소로 저장되어 있던 즐겨찾기 URL을 새 주소로 이전합니다.
Google Drive 즐겨찾기 동기화를 사용하는 경우에도 저장된 즐겨찾기 주소가 함께 이전되도록 처리했습니다.
```



## 향후 개편 예정

기존 Roadmap에 포함되어 있던 개별 기능 계획은 현재 기준으로 다시 검토하고 있습니다.

오랜만에 코드를 다시 점검하면서 개선이 필요한 부분들을 전반적으로 재정리하고 있으며, 2026년 7월 중에는 POE2 Trade Butler의 사용성, 안정성, 즐겨찾기/히스토리 관리, 거래소 페이지 대응 방식을 중심으로 대대적인 개선을 진행할 예정입니다.

이번 도메인 변경 대응 이후에도 불편한 점이나 동작하지 않는 기능이 있다면 [GitHub 이슈](https://github.com/NERDHEAD-lab/POE2-Trade-Butler/issues) 또는 `nerdlab.kr@gmail.com`으로 알려주세요.
