## Notice

### 3.0.1 更新 - 支援 Kakao Games 交易站網域變更

POE2 Trade Butler 自 3.0.0 發布後一直以穩定狀態維護，近期沒有進行大的功能變更。

本次 3.0.1 是針對韓國 POE2 交易站網址遷移到 Kakao Games 網域的維護更新。
```
原 Daum 交易站網址:
https://poe.game.daum.net/trade2/...

新 Kakao Games 交易站網址:
https://poe.kakaogames.com/trade2/...
```

本次更新包含以下內容。

```
擴充功能已支援在 Kakao Games 交易站網域下執行。
使用舊 Daum 交易站網址儲存的搜尋紀錄會遷移到新網址。
使用舊 Daum 交易站網址儲存的最愛 URL 會遷移到新網址。
使用 Google Drive 同步最愛時，已儲存的最愛 URL 也會一併遷移。
```

## 後續改進計畫

此前 Roadmap 中的單項功能計畫將基於目前程式碼狀態重新評估。

在重新梳理長期維護後的程式碼後，計畫於 2026 年 7 月圍繞易用性、穩定性、最愛/歷史管理以及交易站頁面適配進行整體改進。

如果本次網域變更更新後仍遇到不便或無法正常運作的功能，請透過 [GitHub Issues](https://github.com/NERDHEAD-lab/POE2-Trade-Butler/issues) 或 `nerdlab.kr@gmail.com` 告知我們。
