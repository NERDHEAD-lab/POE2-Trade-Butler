## Notice

### 3.0.1 更新 - 支持 Kakao Games 交易站域名变更

POE2 Trade Butler 自 3.0.0 发布后一直以稳定状态维护，近期没有进行大的功能变更。

本次 3.0.1 是针对韩国 POE2 交易站地址迁移到 Kakao Games 域名的维护更新。
```
原 Daum 交易站地址:
https://poe.game.daum.net/trade2/...

新 Kakao Games 交易站地址:
https://poe.kakaogames.com/trade2/...
```

本次更新包括以下内容。

```
扩展程序已支持在 Kakao Games 交易站域名下运行。
使用旧 Daum 交易站地址保存的搜索历史会迁移到新地址。
使用旧 Daum 交易站地址保存的收藏 URL 会迁移到新地址。
使用 Google Drive 同步收藏时，已保存的收藏 URL 也会一并迁移。
```

## 后续改进计划

此前 Roadmap 中的单项功能计划将基于当前代码状态重新评估。

在重新梳理长期维护后的代码后，计划于 2026 年 7 月围绕易用性、稳定性、收藏/历史管理以及交易站页面适配进行整体改进。

如果本次域名变更更新后仍遇到不便或无法正常工作的功能，请通过 [GitHub Issues](https://github.com/NERDHEAD-lab/POE2-Trade-Butler/issues) 或 `nerdlab.kr@gmail.com` 告知我们。
